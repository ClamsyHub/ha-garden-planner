# Brand assets

Original Garden Planner calendar/sprout artwork, MIT licensed with this project.
`icon.png` is 256 × 256; `icon@2x.png` is 512 × 512, transparent PNG.
The square mark also serves as the logo; no duplicated logo files are needed.
Source: `docs/brand/icon.svg`. Regenerate from frontend/ with
`node scripts/render-brand.mjs` after installing the Playwright Chromium browser.
No Home Assistant branded artwork or external fonts are used.

Reference: https://contributors.home-assistant.io/core/integrations/brands/
