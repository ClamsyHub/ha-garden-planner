# Garden Planner v0.1.1

**Requires Home Assistant 2026.7.0 or newer.** Versions below 2026.7.0 contain
upstream CVE-2026-91130 in the native Statistics Graph card. Update Home Assistant
itself; installing Garden Planner does not patch your HA host.

## Changes

- Week view now shows seasonal windows overlapping the selected week, clipped
  to actual days, with search/category/activity filters. Concrete tasks and
  recorded events remain in their own day grid.
- Sensor selection uses an anchored, searchable in-page list instead of the
  native browser datalist. It stays in the visible dialog, supports long lists,
  mouse, touch and keyboard, and still allows manual entity IDs.
- Replace the vulnerable HA 2026.6 development dependency with patched 2026.7;
  CI covers the patched minimum and current stable >=2026.11.

## Compatibility, update and migration

HA >=2026.7.0. Install/update from this Integration custom repository in
HACS/Marketplace, restart HA when requested and reload the panel page.
Compiled frontend, local brand images and license notices are included.

Database schema remains **2**, exchange format **1**. No database migration is
introduced by this update. Garden data stays outside the component directory.
Back up garden data and HA configuration before updating; existing notification
settings and editing grants belong to the HA configuration backup.

Version 0.1.1 is an early 0.x release, not a claim of stable 1.0 maturity. Official
catalog membership is a separate maintainer decision; Custom Repository
installation remains available while any submission is under review.
