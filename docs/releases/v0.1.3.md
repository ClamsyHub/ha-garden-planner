# Garden Planner v0.1.3

Requires Home Assistant >=2026.7.0. Restart Home Assistant after updating and reload the Garden Planner page.

## Calendar

All seven activities have distinct colors, filters and year-view bars. Calendar, overview and plant-detail windows use this order: start indoors, direct sowing, prick out, transplant, care, harvest, other. Start month/day orders windows within each activity. Concrete weekly tasks and events use the same activity order.

## Users and notifications

Administrators manage a table of HA users with viewing/editing checkboxes. Editing includes viewing; administrators retain full access. Existing users keep their viewing access until it is explicitly changed. These permissions protect Garden Planner's panel and data API. Native HA sensors/calendar continue to follow Home Assistant permissions.

Push and email can be enabled independently for each user and mapped to an actual notification destination. New recipients default off. A notification entity is an existing `notify.*` entity, not an email address. For legacy email actions such as `notify.email`, enter an explicit recipient address in the user's email row; modern SMTP recipient entities are configured in Home Assistant and selected from the destination list.

The existing shared channel is preserved and sends in addition to per-user routes. Clear it to use only the table. Identical destinations receive at most one attempt per task/window/date; failed/uncertain attempts are not automatically retried. One failed route does not stop other routes. Disabled/inactive users' routes are skipped. New destinations can receive previously unattempted reminders from the existing seven-day catch-up window. No test messages or new recipients are activated automatically.

## Data and updates

Database schema 2 and exchange format 1 are unchanged. User roles and notification destinations are stored in HA integration options, outside garden exports; include HA configuration in backups. Existing plants, windows and cultivation history are preserved. No additional services or containers are required. This remains an early 0.x release; catalog acceptance is independent.
