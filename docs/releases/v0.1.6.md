# Garden Planner v0.1.6

## Änderungen

- Mehrfachauswahl für Kategorien und Tätigkeiten im Aussaatkalender. Innerhalb eines Filters gilt ODER, zwischen Kategorie/Tätigkeit/Suche gilt UND. Keine Auswahl zeigt alle Werte.
- Fixierte Monatsüberschriften und linke obere Eckzelle der Jahresansicht. Lange Listen scrollen im eigenen begrenzten Bereich, auch auf dem Smartphone.
- Entzogenes Leserecht blendet den Garden-Planner-Link über die native HA-Seitenleisten-Einstellung aus. Erneute Freigabe stellt nur von Garden Planner ausgeblendete Links wieder her. Andere Menüeinträge/Reihenfolgen bleiben erhalten. Administratoren behalten Zugriff; ohne andere Lesefreigaben ist das Panel zusätzlich auf Administratoren beschränkt.
- Dokumentation beschreibt zuerst die direkte Katalogsuche. Garden Planner wurde am 9. November 2026 offiziell in den HACS-Community-Katalog aufgenommen; Custom Repositories bleiben eine Alternative.

## Update

Home Assistant **>=2026.7.0**. Über HACS/Marketplace aktualisieren, HA neu starten und die Panel-Seite neu laden. Vor Updates die HA-Konfiguration sichern. Datenbankschema **3** und Austauschformat **1** bleiben unverändert; keine neue Datenmigration von v0.1.4/v0.1.5. Bei Updates von v0.1.3 oder älter gelten zusätzlich die [Migrationshinweise zu v0.1.4](v0.1.4.md).

Die Seitenleisten-Sichtbarkeit ist eine native Benutzereinstellung, keine neue Sicherheitsgrenze. Direkte Datenzugriffe bleiben serverseitig gesperrt. Ein Nutzer kann den Link über seine HA-Seitenleistenbearbeitung selbst wieder einblenden, erhält dadurch aber keine Datenrechte. Ältere geöffnete Clients gegebenenfalls neu laden. Bestehende Benachrichtigungsziele werden nicht aktiviert oder verändert.

## English

Calendar category/activity filters now support multiple values across year, month and week (OR within a filter, AND between filters). Year headings and the top-left cell stay visible inside the scrollable year grid. Revoking viewing hides the native HA sidebar link; re-granting access restores only integration-owned hides. Other sidebar preferences are preserved, and administrators always retain access. New users and role changes are synchronized too.

Garden Planner joined the official HACS community catalog on 9 November 2026. Installation docs now lead with catalog search and retain custom repositories as a fallback. Sidebar visibility is cosmetic; backend authorization still protects direct access. Users can manually re-show a native sidebar link without receiving data permissions. Restart HA and reload the panel after updating. HA >=2026.7.0, schema 3 and exchange format 1 remain required/unchanged. See v0.1.4 migration notes when upgrading from older versions.
