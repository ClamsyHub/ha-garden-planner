# Garden Planner v0.1.0 — first public development version

**Development preview, not the stable 1.0 release. Back up your Home Assistant
configuration and garden data before installing or updating.**

## Compatibility and installation

- Home Assistant >=2026.6.0; native compatibility tests cover 2026.6 and 2026.11.
- Install this repository as an **Integration** custom repository in HACS or
  Marketplace. Enable pre-releases to select this development release.
- Restart HA and add Garden Planner in Settings → Devices & services.
- The sidebar panel and compiled frontend are included; no YAML, extra Docker
  container, separate card, cloud account or frontend build is required.
- The integration is not yet included in the official community catalog.

## Included

- German/English plant, variety, seasonal window and bed management.
- Actual sowings, dated lifecycle events and permanent multi-year history.
- Interactive month/week/year calendar, filters, tasks and historical snapshots.
- Local SQLite worker, transactions, migrations and optimistic edit protection.
- Reviewed JSON/CSV ZIP exchange and consistent local backups/managed restore.
- Automatic native panel, five count sensors and one read-only task/event calendar.
- Optional existing temperature sensors (air/soil/substrate, °C/°F/K).
- Admin-managed editor grants and explicitly opt-in reminders.

## Data and migrations

Initial public database schema: **2**, JSON exchange format: **1**.
No migration from a previous public version exists. Internal development-schema
migration and rollback are tested. Garden data lives under `/config/garden_planner/`,
outside the replaceable component directory. Full HA backups must also include
ConfigEntry options/editor grants. Garden imports and managed restore preserve
current notification reservations and never enable reminders.

## Known limitations

One shared garden; active HA users can read it. Administrators manage configuration
and file exchange; additional editors may be explicitly granted write access.
No bundled horticultural recommendations, physical sensor history, crop rotation,
photos or seed inventory. HA's native calendar is read-only and shows concrete
tasks/events; seasonal windows remain in the dedicated panel.

Reminders default off. Each task/window/date has at most one durably reserved send
attempt. Failed or uncertain calls are not automatically retried, so delivery is
not guaranteed. A successful HA service call is not a device acknowledgment.
The development version has automated browser/HA tests and an isolated Container
smoke test; physical devices and Companion Apps need further user testing.
