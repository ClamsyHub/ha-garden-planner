# Garden Planner v0.1.2

Release candidate: not yet published. Publication requires owner approval.

## Changes

- Add, change or clear the optional variety when editing a growing window. The variety must belong to the selected plant. Historical cultivation snapshots remain unchanged.
- Remove duplicate germination temperature, germination duration and cultivation duration inputs from growing windows. Plant/variety master data remain available; existing window data are retained.
- Show compact variety rows with the name and optional botanical name in parentheses. Full data remain available in the editor.
- Sort plant-detail growing windows by start month/day, with activity order as a tie-breaker. Show activity, optional variety, date range and notes; retain all other information in the editor.

## Compatibility and update

Requires Home Assistant >=2026.7.0. Database schema 2 and exchange format 1 are unchanged; no manual data migration is needed.

After publication, update through HACS/Marketplace, restart Home Assistant and reload the Garden Planner page. A GitHub source push alone does not update installed v0.1.1 packages. Both the updated backend and bundled frontend are required for editable variety assignments.

Back up your Home Assistant configuration and garden data before updating. The integration remains an early 0.x version; catalog acceptance is independent of this release.
