# Garden Planner v0.1.4

**Datenmigration auf Schema 3:** Beim ersten Start werden die bisherigen Keimtemperatur-, Keimdauer-, Kulturdauer-, Saattiefe- und Abstandsangaben der **Sorten** aus den Stammdaten entfernt. Bestehende Anbauzeiträume werden von ihrer Sorte gelöst und gelten für die Pflanze. Die Integration erstellt vor der Migration eine Datenbanksicherung unter `/config/garden_planner/backups/`. Zusätzlich vor dem Update die HA-Konfiguration sichern. Ein reiner Code-Downgrade auf v0.1.3 genügt nicht; dafür Home Assistant stoppen und die alte Datenbanksicherung zusammen mit dem alten Integrationscode wiederherstellen oder die vollständige HA-Sicherung zurückspielen. Eine Wiederherstellung über die laufende v0.1.4 normalisiert die Daten erneut auf Schema 3.

Angaben an der Pflanze, Sortennamen, Notizen, Zeiträume und historische Aussaaten einschließlich ihrer gespeicherten Momentaufnahmen bleiben erhalten. Bestehende Zeiträume werden weder zusammengeführt noch gelöscht.

## Änderungen

- Stabilere Sensorauswahl beim Fokussieren und Scrollen auf iPhone-WebKit.
- Erreichbarer Home-Assistant-Menüknopf oben, auch auf schmalen Smartphone-Ansichten. Kein Drehen des Displays zum Öffnen der Seitenleiste erforderlich.
- Sortenformulare enthalten keine Keimtemperaturen, Keim-/Kulturdauern, Saattiefe oder Pflanz-/Reihenabstände mehr. Alte Exporte können diese entfernten Stammdaten nicht erneut einspielen.
- Anbauzeiträume ohne Sortenauswahl. Tatsächliche Aussaaten können weiterhin einer Sorte zugeordnet werden.
- Saattiefe allein links; Pflanz- und Reihenabstand gemeinsam in einer neuen Zeile.
- Kompakte Pflanzenkennwerte, aufklappbare vollständige Informationen und Sprungknöpfe zu Sorten, Zeiträumen und Beobachtungen.

## Update

Requires Home Assistant >=2026.7.0. Update via HACS/Marketplace, restart Home Assistant and reload the Garden Planner page. Database schema is now **3**; exchange format remains **1**. Older exports/backups are normalized on import/restore. Notification destinations and access settings are preserved; no recipients are activated.

## English

Schema 3 intentionally removes the retired numeric variety traits and makes existing growing windows plant-wide. A pre-migration database backup is created automatically. Back up HA configuration too; reverting only the integration code cannot read schema 3. Restore the pre-migration database to roll back to v0.1.3. Plant traits, notes, varieties and historical cultivation snapshots remain intact.

The panel gains a persistent HA sidebar menu button, simplified forms, compact plant facts and expandable full details. Actual cultivations still support varieties. Restart HA and reload the browser after updating. Tested with desktop/mobile Chromium and desktop/mobile WebKit; the iPhone profile is browser emulation, not a physical iOS 27 device certification.
