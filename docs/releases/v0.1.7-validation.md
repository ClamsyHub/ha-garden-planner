- Matrix tests cover reader-owned changes, persistence, disabled missing activities, enabled new activities and rollback after rejected saves. Task tests cover overview generation, opening a task from the weekly calendar as a reader, completion, reload persistence, cancellation/reactivation without resetting completed work, and isolation from another user's task IDs.
- 65 backend unit tests and 29 native HA tests per supported target (2026.7.0 / 2026.11.0) cover stable annual task IDs, next-year recurrence, completed history, source removal/date changes, overdue work, winter/leap dates and optimistic revisions.
- Real native tests verify private atomic HA storage, restart reload, read-only completion, foreign-ID rejection, no private-data leakage to shared entities/channels, task generation with delivery disabled, personal push/email routing, unchanged manual-task notifications and existing delivery reservations. Notification services are synthetic stubs; no external messages are sent.
- Integration unload drains in-flight personal completion before closing storage. A failed private archive does not stop other users or shared-task notifications. Normal task writes are verified by read-back, including actual HA-logged write failures. Rejected saves do not alter the in-memory ledger; malformed private storage is rejected rather than silently regenerating task history. Strict mypy, Ruff, TypeScript, formatting and reproducible bundle checks remain enabled.
- Shared SQLite schema 3 / exchange format 1 remain unchanged. Personal task histories and preferences require a full HA configuration backup and are intentionally excluded from shared garden exports and HA calendar/count entities.
