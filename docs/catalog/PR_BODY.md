## Integration summary

Garden Planner is a local sowing, planting, care and harvest planner with permanent
multi-year cultivation history. A bundled German/English panel provides plant,
variety, bed and actual-sowing management, seasonal calendars, tasks and history.
SQLite user data remains outside the integration installation directory. Optional
temperature sensors and explicitly opt-in reminders use existing HA facilities.

This submission is for the `integration` category and the `garden_planner` domain.
It does not replace a core integration. Local original brand icons are included.
Custom Repository installation has been tested with HACS and native Marketplace.
Version 0.1.1 will require HA >=2026.7.0; it remains an early 0.x project.

No catalog membership is claimed before maintainer acceptance.
